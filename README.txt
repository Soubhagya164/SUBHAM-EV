SUBHAM EV – TRANS MOBILITY
============================

1. Copy this folder into your preferred project location, or use it directly in VS Code.
2. Make sure Flask is installed in your virtual environment:
   python -m pip install flask
3. Run:
   python app.py
4. Open:
   http://127.0.0.1:5000

IMPORTANT:
- The uploaded SUBHAM EV logo is already included at:
  static/images/logo.jpg
- The scooter visuals are temporary CSS graphics.
- Replace the vehicle cards with your actual scooter photos later.
- Replace the sample phone, email and address in templates/index.html.
- The test ride form is currently frontend-only. Next we can connect it to Flask + SQLite.
